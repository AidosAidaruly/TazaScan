# Security Policy

## Supported Versions

TazaScan is currently under active development as an academic diploma project.

| Version | Supported |
| --- | --- |
| Development (main) | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in TazaScan, please do not disclose it through public GitHub Issues.

Instead, use GitHub's private vulnerability reporting feature, if enabled, to submit a confidential security report.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The potentially affected components.
- Suggested mitigation, if available.

Security reports will be reviewed as development resources permit.

## Security Considerations

- Never commit passwords, private API keys, access tokens, or database credentials.
- Use environment variables for sensitive configuration.
- Avoid exposing personal user data or production database contents.
- Review dependencies and security alerts regularly.

TazaScan is an academic prototype under development and is not intended for production or medical use.
