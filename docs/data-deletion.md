# TazaScan Data Deletion

MVP draft. This process should be reviewed before a large-scale public launch.

## Local Device Data

Scan history and favorites are stored locally on the user's device. Users can clear history inside the app. Removing favorites deletes local favorite records.

Uninstalling the app should remove local app storage managed by the operating system.

## Uploaded Submissions

Product submissions and package photos are stored on the backend for moderation. To request deletion, provide enough information to identify the submission:

- barcode
- product name
- approximate submission date
- package photo description

## Admin Action

An administrator should verify the request, delete or anonymize the related submission, and remove uploaded images where appropriate.

## Future Accounts

When user accounts are added, TazaScan should provide authenticated self-service export and deletion workflows.
